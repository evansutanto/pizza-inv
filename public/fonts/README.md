# Helvetica Neue

Source supplied by the project owner: [Helvetica Neue font family](https://font.download/font/helvetica-neue-5). The source page labels the pack **free for personal use**. Original copyright and trademark notices are retained in the font metadata and [Helvetica-Neue-notices.txt](Helvetica-Neue-notices.txt).

The site bundles Latin WOFF2 subsets of `HelveticaNeueRoman.otf` (400), `HelveticaNeueMedium.otf` (500), and `HelveticaNeueBold.otf` (700). These are Helvetica Neue, not the custom NeueHelveticaDOT family. CSS and canvas text both use the same local faces.

Converted with fontTools 4.69.1 and Brotli 1.2.1, preserving font names and notices. Subset coverage: U+0020–024F, U+2000–206F, U+20A0–20CF, U+2122, U+2212. Runtime assets live in `src/assets/fonts/`; conversion tools are not runtime dependencies.
